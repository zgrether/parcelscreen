Try it (example parcels and results; simplified geometry)
  1. Tap 52-47A to select it; tap it again to unselect. Select it and tap the acres on the toolbar: the Layers panel opens.
  2. Add: tap 52-42A and 52-61 (across the road), Done. Or Draw a custom area onto it. Each part is a layer; the road strip too.
  3. Select a layer to see its Info and highlight it. × takes a parcel back out. Add a note on the parcel.
  4. House, tap to place. Tap the bulls-eye: its layer is selected; hide it or delete it.
  5. Run screen (example) below: results arrive as layers. Hide the horizon, remove site #2 from the analysis.
  6. Tap the built parcel (or empty map) to close it: it stays on the map (amber) and in History. Tap it to reopen. The trash on the toolbar deletes it.
