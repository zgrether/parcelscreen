# Map label glyphs

`Noto Sans Regular/0-255.pbf`: MapLibre glyphs (signed-distance-field PBF) for the Basic Latin and Latin-1
range of **Noto Sans Regular**, used for the contour labels (step 13g). Copied on 2026-10-07 from MapLibre's
demo glyph server (`https://demotiles.maplibre.org/font/Noto Sans Regular/0-255.pbf`).

Noto Sans is © Google, licensed under the **SIL Open Font License 1.1** (https://openfontlicense.org).
Only this one range is shipped: the labels use digits, commas, spaces and "ft".
